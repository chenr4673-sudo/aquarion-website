# AI 手臂摔跤训练计划定制网站

专业的AI驱动手臂摔跤（腕力）训练计划生成系统。

## 核心功能

### 1. 能力评估页面
收集三类关键数据：
- **身体硬件数据**：手掌长度、小臂长度
- **训练频率**：每周3-5天训练
- **动作能力数据**：按9个类别分类的30+个专项动作的当前重量

### 2. AI技术分析页面
基于身体硬件和能力数据，AI智能推荐：
- 主技术路线（低位顶峰、高位顶峰、高位勾手、内侧勾手、外侧勾手等）
- 副技术路线
- 硬件优势分析
- 当前短板
- 训练重点建议

### 3. 训练计划页面
- **第一周数据**：严格来自用户评估填写的重量
- **周期递进**：每个动作独立进度管理
  - 5RM×5组类：5×5 → 3RM×10 → 4RM×8 → 5RM×7 → 6RM×6 → 加重回5×5
  - 20-30RM×5组类：20RM → 25RM → 30RM → 加重回20RM
  - 三七训练法：每周加0.5-1kg
  - 其他类型按各自规则递进
- **周切换功能**：支持查看下一周、返回上一周
- **训练频率适配**：根据每周3/4/5天自动安排训练日

## 设计风格

- **配色**：深色背景 + 红色主题 + 银色辅助色
- **风格**：专业、力量感、运动科技感
- **无圆角**：极简硬朗的视觉风格
- **响应式**：适配手机端和电脑端

## 技术栈

- React + TypeScript
- React Router (Data Mode)
- Tailwind CSS v4
- Motion (React动画)
- Radix UI组件
- Supabase后端（可选）

## 开始使用

1. 访问首页，了解训练系统
2. 点击"开始能力评估"
3. 依次填写身体数据、训练频率、动作能力
4. 查看AI技术分析和建议
5. 获取个性化训练计划

## 训练理论

严格遵循专业手臂摔跤训练理论：
- 内侧力、外侧力、横向力、前端专项全面覆盖
- 每周至少3次训练确保完整覆盖所有力量方向
- 前端专项每次训练日必须包含3-4个动作
- 5×5周期训练法严格按照训练次数递进，而非简单每周加重
